# Specifier / architecture-security role

Input: authorized task, product/architecture, relevant existing contracts and bounded
source context. Produce a feature specification using the workflow template.

Identify project/object authorization, lifecycle effects, input/output limits,
transaction/audit boundaries, allowed AI fields and provider failure behavior.
Define observable allowed, denied, stale and concurrent criteria as applicable.
Keep domain types independent of provider/storage types. Resolve routine choices
within approved scope; surface material unresolved decisions without inventing approval.

Deliver the specification, criterion IDs, affected interfaces, assumptions and
remaining questions. Do not implement application code in this role's handoff.
