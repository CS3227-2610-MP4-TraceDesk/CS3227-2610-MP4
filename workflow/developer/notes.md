# Developer working notes

Use this file for concise, verified summaries that help a later human or agent resume
work. Link to source files and evidence instead of copying long prompts or outputs.

For each dated entry record:

- Goal and current state.
- Applicable criterion/specification.
- Decisions and brief rationale.
- Files changed and interfaces affected.
- Commands and results.
- Blockers, failed attempts and next owner/action.
- Context supplied upfront versus retrieved later.
- Observable calls, retries, duration and tokens/costs (unknown when unavailable).

Do not store private chain-of-thought, credentials, environment files, real user
content, session identifiers, raw provider responses or unreviewed interaction logs.
