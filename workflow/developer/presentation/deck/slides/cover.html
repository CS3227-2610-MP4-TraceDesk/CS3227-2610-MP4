Hi. Our MP4 is TraceDesk, and for my part I ran a small experiment on how much a coding agent needs to read. I gave two coding agents the same jobs. One could only read a short list of files I chose. The other could read anything in the project. Then a third agent reviewed both versions without knowing which was which. I ran it on a real feature of our project, so the code I kept from these runs is now part of TraceDesk.
