A few things limit what these results can show. First, I only ran three pairs, once each, so another run might come out differently. Second, I chose A's file list myself, and the rule A missed was kept in a Reporter document instead of a shared one. With that rule in the right place, A might have got job 1 right, so job 1 partly tests our documents and not just the idea of a short list. Third, the checker is the same model as the writers, so it might miss the same things. That's why I checked every finding myself. Fourth, A and B ran at the same time on my laptop, so the times are only rough, but that does not change the token counts.
