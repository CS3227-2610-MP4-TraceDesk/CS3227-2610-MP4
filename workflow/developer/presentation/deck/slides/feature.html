First, the feature I was building. TraceDesk is a bug tracker with three roles: reporter, developer and QA. My part is the developer side. This feature lets the developer who is assigned to a bug ask an AI for possible causes and next steps. The developer chooses which parts of the report go to the AI, for example the description, the logs or their own notes. The AI's answer is only advice: it cannot change the report or its status. If the developer likes a suggestion, they can edit it and save it as a private note. The three blue boxes are the core pieces I built during this experiment: the permission checks, building what is sent, and checking the AI's reply. The permission checks actually run three times: before anything is selected, before sending, and before showing the result, so if someone is removed from the bug mid-request, they don't get the answer. The web endpoint and the screen are the next step.
