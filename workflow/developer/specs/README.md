# Developer contributor specifications

Store contributor planning and issue breakdowns here. The canonical application
behavior contract belongs at `workflow/specs/developer-investigation.md` and must be
linked from `workflow/acceptance-criteria.md` before implementation.

Planned personal artifacts may include:

- A Developer slice/issue breakdown.
- A task-specific experiment protocol.
- Presentation case-selection criteria.

Do not copy Reporter specifications or mark proposed criteria complete without
implementation and evidence.
