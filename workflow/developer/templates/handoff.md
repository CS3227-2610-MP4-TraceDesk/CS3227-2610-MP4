# Developer agent handoff template

Copy for an actual handoff. Blank fields are not evidence of execution.

- Task / feature ID:
- From agent / role and to agent / role:
- Trigger and timestamp (UTC):
- Scope and exclusions:
- Authorization / criteria references:
- Trusted instructions versus untrusted input:
- Revision and working-tree changes:
- Owned files and shared-file coordination:
- Minimal required context and retrieval links:
- Expected deliverable and stop condition:
- Security / privacy / lifecycle / concurrency risks:
- Commands and results already obtained:
- Resource budget and calls/retries/time/tokens actually observed:
- Decisions, brief rationale, disagreements and blockers:
- Next action and responsible actor:

Use `unknown` for unavailable telemetry. Preserve a summary and source links, not
private reasoning, copied conversations, secrets or raw logs containing user content.
