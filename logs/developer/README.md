# Developer contributor interaction summaries

Add one dated Markdown summary for each meaningful Codex-assisted task, for example:

`2026-11-07-developer-workflow-setup.md`

Each summary should include:

- Goal and bounded scope.
- Applicable specification or criterion.
- Codex/agent roles actually used.
- Context supplied and later retrieved.
- Decisions and changes produced.
- Commands/tests and their outcomes.
- Human verification or corrections.
- Observable calls, retries, elapsed time and tokens/costs, using `unknown` when absent.
- Follow-up action and owner.

Keep the summary sanitized and verify it before committing.
